# Домашнє завдання №5: Closure, Generators, Decorators

Цей репозиторій містить рішення чотирьох завдань з курсу Python Core, присвячених функціональному програмуванню та обробці помилок.

## 📂 Структура проєкту

### 1. Завдання: Кешування чисел Фібоначчі (`task_1.py`)
Реалізовано функцію `caching_fibonacci`, яка використовує **замикання (closure)** для створення кешу. 
- Це дозволяє уникнути повторних обчислень для одних і тих самих значень.
- Значно підвищує швидкість роботи рекурсивного алгоритму.

### 2. Завдання: Генератор прибутку (`task_2.py`)
Робота з ітераторами та регулярними виразами:
- `generator_numbers`: функція-генератор, що знаходить усі дійсні числа у тексті за допомогою `re.finditer`.
- `sum_profit`: функція вищого порядку, яка підсумовує числа, отримані від генератора.


### 3. Завдання: Аналіз лог-файлів (`task_3/`)
Проєкт для парсингу та аналізу лог-файлів. Скрипт зчитує файл логів, фільтрує їх за рівнем (INFO, ERROR, DEBUG) та виводить статистичну таблицю у консоль.

### 4. Завдання: Консольний бот-помічник (`task_4.py`)
Вдосконалена версія бота з попереднього модуля. 
- **Головна особливість:** реалізовано декоратор `@input_error`, який обробляє винятки `KeyError`, `ValueError` та `IndexError`.
- Завдяки декоратору бот не "падає" при некоректному введенні, а виводить зрозумілу підказку користувачу.
