###### Project Overview (EN)
This repository contains solutions for the fifth homework of the Python Core course. The tasks focus on functional programming, closures, generators, and advanced error handling using decorators.

###### 📂 Project Structure
1. **Fibonacci Caching (`task_1.py`)**: Implementation of a recursive Fibonacci function with a closure-based caching mechanism to optimize performance.
2. **Profit Generator (`task_2.py`)**: A script that uses regular expressions and generators to identify and sum floating-point numbers within a text.
3. **Log Analysis (`task_3/`)**: A tool for parsing log files, calculating statistics by severity level (INFO, ERROR, etc.), and displaying them in a formatted table.
4. **Assistant Bot (`task_4.py`)**: A console-based bot with a robust `@input_error` decorator that handles `KeyError`, `ValueError`, and `IndexError` exceptions gracefully.

###### 🚀 Usage
1. Clone the repository:
   ```bash
   git clone https://github.com/olgadeyneka77/goit-pycore-hw-05.git
   ```
2. Run any task using Python:
   ```bash
   python task_4.py
   ```


#### Огляд проєкту (UA)
   
Цей репозиторій містить розв’язання п’ятого домашнього завдання з курсу Python Core. Завдання присвячені функціональному програмуванню, замиканням, генераторам та просунутій обробці помилок за допомогою декораторів.

###### 📂 Структура проєкту
1. **Кешування Фібоначчі (`task_1.py`)**: Реалізація рекурсивної функції Фібоначчі з механізмом кешування на основі замикання для оптимізації продуктивності.
2. **Генератор прибутку (`task_2.py`)**: Скрипт, що використовує регулярні вирази та генератори для пошуку та підсумовування дійсних чисел у тексті.
3. **Аналіз логів (`task_3/`)**: Інструмент для парсингу лог-файлів, обчислення статистики за рівнями (INFO, ERROR тощо) та виведення її у вигляді форматованої таблиці.
4. **Бот-помічник (`task_4.py`)**: Консольний бот із використанням декоратора @input_error, який надійно обробляє винятки KeyError, ValueError та IndexError.
